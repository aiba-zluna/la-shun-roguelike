# La shun

La Shun is a 2D roguelike game developed in Unity as our first game development project.

Embark on a perilous rescue mission as La Shun, a determined warrior venturing into the Shrouded Realm to save his kidnapped wife, Xi Na. Battle relentless hordes of enemies, explore ever-changing maps, and grow stronger with every run. Adapt your strategy, overcome increasingly dangerous challenges, and fight your way through the cursed realm to reunite with your loved one.

## Built with
 - Unity
 - C#
 - Github

## Roadmap
 - 6 stages with 4 rooms each.
 - Scaling enemy stats.
 - Buff system
 - Debuff system
 - RNG enemy spawn system
